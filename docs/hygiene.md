# Hygiene rules

1. No keys, no decryption. 2. No Microsoft files in the repository. 3. Licensed SDK at build
time only; nothing derived from it is published. 4. Provenance for every fact. 5. Users supply
their own unpacked titles; the project never helps obtain games, SDKs or system software. 6. No current-title marketing. 7. Title-specific behaviour in data.
8. AI assistance disclosed and verified. 9. Licence hygiene (SPDX per file). 10. Legal review
before any publication.

- Never add patch files for titles (`*.patches.txt`, `patches.txt`): user patches are user data (docs/patches.md); only the mechanism lives here.
